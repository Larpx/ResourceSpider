# ResourceSpider 用户使用说明

面向日常使用人员。更偏技术的构建、架构与扩展说明见 [开发说明](开发说明.md)。仓库入口见 [README](../README.md)。

## 这是什么

ResourceSpider 是一套分布式网络采集系统：可用网页管理界面创建与管理采集任务，也可在本机单独跑采集节点。支持普通网页请求、浏览器页面采集等多种方式，结果可落到文件或数据库。

## 你需要准备什么

- 一台能运行程序的电脑（或服务器）
- 数据库（一般使用 MySQL）
- 可选：缓存服务、消息队列（分布式场景更稳）
- 可选：Docker（一键拉起整套环境）

## 程序大致怎么跑

1. 准备好数据库，并完成初始化。
2. 启动**服务端**（提供网页管理界面与接口）。
3. 用浏览器打开管理界面，登录后创建或编辑采集任务。
4. 启动一台或多台**采集节点（Agent）**，让它们连接服务端或按本地任务文件执行。
5. 在管理界面查看进度、结果与节点状态；需要时暂停、恢复或停止任务。

## 怎么启动（口语版）

### 用 Docker 一键启动（适合快速体验）

进入部署目录，按说明启动整套服务后，用浏览器访问本机管理界面即可。默认管理入口一般是本机 `5000` 端口。

### 本机分别启动（适合日常使用）

1. 先完成数据库初始化。
2. 启动服务端，浏览器打开管理界面。
3. 再启动 Agent：
   - **本地模式**：读取本机任务文件并写出结果
   - **在线模式**：连接服务端领取任务并回报结果

具体命令与路径见 [开发说明](开发说明.md) 的「环境 / 构建 / 运行」。

## 主要功能怎么用

| 功能 | 你可以做什么 |
|------|----------------|
| 仪表盘 | 看系统概况、节点与任务概况 |
| 任务管理 | 创建、编辑、执行、暂停、恢复、停止任务；查看执行记录与配置版本 |
| Agent 管理 | 查看节点在线状态、分组与基本信息 |
| 表达式管理 | 配置字段提取规则，检查是否可用 |
| 代理管理 | 维护代理池，做连通性测试 |
| 运行时监控 | 看实时日志、任务进度与资源情况 |
| 系统设置 | 用户与系统相关设置 |

### 使用建议

- 先用少量 URL 或简单任务验证流程，再放大规模。
- 需要稳定长时间采集时，优先「服务端 + 在线 Agent」。
- 只想本机试跑时，可用 Agent 本地模式。
- 重要任务改配置前，先在界面确认版本/回滚能力是否满足你的需要。

## 常见问题

| 现象 | 你可以怎么做 |
|------|----------------|
| 打不开管理界面 | 确认服务端已启动；检查浏览器地址与端口是否正确 |
| Agent 一直离线 | 确认 Agent 已启动；在线模式下核对服务端地址与节点身份配置 |
| 任务一直不跑 | 确认任务已触发执行，且至少有一个可用 Agent |
| 采集结果为空或不对 | 检查目标站点是否可访问；核对提取规则与步骤设置；先缩小范围试跑 |
| 数据库相关报错 | 确认数据库已启动、初始化脚本已执行、连接信息正确 |
| Docker 起不来 | 确认 Docker 已安装且可用；查看编排日志，按提示处理端口占用或依赖服务未就绪 |
